- **Linux and Windows can bootstrap complete native toolchains from source.** The unified `pkgs/by-name` package set now traces nested stage0 tools into stage1 Mes, TinyCC, libc, and bash, stage2 GNU userland and binutils, and the stage3 GCC bootstrap ladder; top-level `gcc` is the resulting modern compiler rebuilt with itself, and the Windows stdenv builds ordinary packages with the resulting PE32 toolchain rather than the MSYS2 compiler seed.
